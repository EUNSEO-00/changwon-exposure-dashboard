# 창원시 산업·배출시설 주변 취약계층 공간 노출 탐지 및 환경관리 우선확인 지원 시스템

**시나리오 앙상블 반복성 분류(SERC) 기반 창원시 취약시설 공간 노출도 분석** · 창원시 AI 데이터 활용 공모전

취약시설 **1,609곳**과 산업·배출시설 **6,924곳**(물리적 위치 3,750개)의 공간관계를 정량화하고,
정답이 없는 가정 **36가지를 모두 계산**해 어떤 가정에서도 반복적으로 상위에 남는 시설을 가려낸다.

| 분류 | 기준 (36개 시나리오 중) | 시설 수 |
|---|---|---|
| 반복적 고노출 패턴 | 35회 이상 (95% 이상) | **92곳** |
| 추가 확인 필요 | 2~34회 | **153곳** |
| 반복 상위 노출군 미포함 | 1회 이하 (5% 이하) | **1,364곳** |

전체의 **90.5%(1,456곳)**는 어떤 가정을 적용해도 분류가 바뀌지 않는다.

---

## 실행

```bash
pip install -r requirements.txt
streamlit run dashboard/app.py
```

Python 3.10 이상.

## 구성

```
dashboard/          Streamlit 대시보드
  app.py              진입점 — 공간 노출 지도 · 행정동 관리현황 · 모델 안정성 3개 탭
  tabs/               탭별 화면
  components/         KPI · 상세 패널
  utils/              데이터 경로 · 문구
pes/output/         분석 산출물 (최종 분류 · 시나리오 점수 · 공간 피처 · 검증)
msh/data/processed/ 시설 원장 · 행동 매트릭스 · 행정동 경계
requirements.txt
```

이 저장소는 **대시보드 실행에 필요한 파일만** 담은 배포용이다.
전처리·지오코딩·시나리오 계산 등 분석 파이프라인 전체는 별도 저장소에 있다.
